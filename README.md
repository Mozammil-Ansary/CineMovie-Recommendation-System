# CineMovie — Intelligent Movie Recommendation System

An intelligent movie recommendation system built with Python and machine learning, featuring personalized recommendations, explainable ranking, and evaluation.

## Project Status

Initial project scaffold. The recommendation pipeline will be implemented incrementally from data exploration through deployment.

## Planned Approach

- TMDB 5000 Movie Dataset
- Data preprocessing and feature engineering
- TF-IDF content representation
- Cosine-similarity candidate generation
- Rating/popularity re-ranking
- Diversity-aware recommendations
- Recommendation explanations
- Streamlit interface
- Recommendation evaluation

## Planned Evaluation

- Precision@K
- Recall@K
- NDCG@K
- Coverage
- Diversity
- Latency

## Dataset

The project will use the TMDB 5000 Movie Dataset for the technical assignment. Dataset attribution and usage notes will be documented before final submission.
